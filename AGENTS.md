# Architecture rules
- Cabinet Takeoff unit extraction resolves shared-building labels inside the page-specific function helper; no cross-page number inference is permitted.
- Cabinet Takeoff review and import use the same building-plus-unit identity helper (floor excluded) so separate buildings never merge and a number repeated across floors stays one unit.
- Prefinal Cabinet Count first looks for a saved Unit Count name printed in full on the floor plan (TYPE/UNIT prefixes ignored, spaces/hyphens/slashes interchangeable, longest unique match wins; short codes need a UNIT/TYPE prefix), then resolves the page's own complete code against a unique saved name that owns it; title pages produce no cabinet columns and ambiguous labels remain unassigned to prevent room/prefix guesses.
- Prefinal Cabinet Count locks each page's labels to that page's own PDF text layer (glued labels split, unique partial labels snapped, unprinted labels dropped) so vision/strip passes cannot invent SKUs; raster-only pages skip the lock.
- Prefinal Cabinet Count rows carry their page text so the import step re-matches each page against the Unit Count names saved at import time; names captured when the background upload started may be stale.
